QUESTIONS

Read only, by design.

Will it install or run anything?

No. It never runs a package manager and never installs, builds, executes or downloads anything. It reads lockfiles as text. Execution happens only in Cohen's sandbox.

What leaves my machine?

Package names and versions, nothing else. No source, file paths, environment variables, hostnames or lockfile contents. mantis scan --dry-run prints the exact request before anything is sent.

What about private packages?

Local, git, tarball and workspace packages, private scopes and anything from a private registry are never sent. Each one is listed with the reason it was held back.

Do I need a lockfile?

No. With only a package.json it works out the versions npm would pick from public registry metadata. --offline turns those lookups off.

Which lockfiles?

npm, pnpm, Yarn classic and Berry, and Bun text lockfiles.

Can it gate a build?

Yes. mantis scan exits 1 when anything needs review.

What does it cost?

The binary is free and Apache 2.0 licensed. Checks need a key: a free one covers 100 lookups a day, and paid plans are unlimited. See pricing.
