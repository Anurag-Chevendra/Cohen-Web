INSTRUMENTATION

Some payloads wait to be called.

So every package runs twice: once as it installs, once as it is imported. Two records, weighed equally.

01 · INSTALL

Scripts left on.

Every lifecycle hook runs, traced. It is where most payloads live.

install_phase

02 · IMPORT

Then loaded.

Loaded the way your code would load it. Nothing to load is still a result.

import_phase

One event is noise.
Two, in order, is a finding.

STATIC ENGINE

Reads what shipped. Never decides.

The tarball is examined without running a line. It adds context to the verdict, never the verdict itself.
