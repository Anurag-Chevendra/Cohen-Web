How a package moves through it.

Five stages, in the same order, every run. Nothing carries over from one run to the next.

01

Fresh sandbox

Each run starts from the same pristine container image.

02

Instrumented install

Lifecycle scripts run under system call tracing, isolated from anything real.

03

Import

The package is loaded as a consumer would load it, and traced as a separate record.

04

Attribution

Every action is tied to the process that performed it.

05

Correlation

Events that mean little alone are joined into findings.

TWO ENGINES

One watches it run. One reads what shipped.

Cohen triages; it does not classify. In 1984 Fred Cohen proved that no detector can decide, in general, whether a program is a virus. What remains is observation, and what you do with it.

the value itself is the concern context, kept for the baseline
network.package_connections

Every socket opened by the package's own processes, as ip:port. Registry traffic is attributed to npm and never appears here.

network.dns_lookups_non_npm

Resolutions to anything other than the registry. DNS exfiltration opens no socket; the hostname is the payload.

network.exfil_services_contacted

Known out of band callback and paste services. Close to conclusive on its own, so it is kept apart from general connections.

canaries.canary_tokens_leaked

The container holds planted credentials that exist nowhere else. If one leaves, the package did not just read a secret. It sent one.

canaries.accessed_by_package

Credential paths the package opened: SSH keys, cloud credentials, wallets, CI tokens. Kept apart from ordinary reads because the targeting is deliberate.

canaries.probed_but_absent

Paths it looked for and did not find. Checking for a wallet it has no use for reveals intent, whether or not the file exists.

filesystem.dropped_and_executed

A path written or made executable during the run, then passed to execve. The highest value correlation the engine produces.

filesystem.archives_written

Compressed output, recorded with names intact. Attackers label their loot: ssh.gz, aws.gz, token.gz.

filesystem.recon_dirs_enumerated

Walks across home and root that no build step needs. Raised alongside recon_dir_scan, which flags the pattern rather than the paths.

no_js_entry

True when there was nothing to import, so "nothing ran" is never mistaken for "nothing happened".

STATIC ENGINE

Rules, families and entropy.

The archive is examined without being run. Threats and capabilities are matched separately and never mixed.

threat-*

Severity low, medium or high, with MITRE tactics. Reported with the file, the line and the matched text.

capability-*

What the code can do: outbound network, process spawn, write executable, delete. Context only, never scored; almost every real package holds some.

Rule families

Names are hierarchical, and rules collapse into a family only when two or more share a stem. threat-runtime-obfuscation-{general,base64exec,steganography} becomes one node; threat-runtime-environment-read stays on its own.

Per file measures

A SHA 256 hash for every file, and an entropy score for every file under the size cap.

Entropy

Shannon entropy over byte values, divided by eight, on a scale of 0 to 1. Text sits at 0.52 to 0.65; packed or encrypted data sits near 1. Anything at or above 0.94 is flagged as a likely bundled binary.

Not measured

Files over the size cap are hashed but not measured, and published as null. Missing and low are different claims.

VERDICTS

The edge cases, settled.

Two verdicts, so the only question is whether to look. Each of these cases needed its own rule.

Truncated runs

A run that times out or dies mid trace resolves to review. A clean verdict with no observation behind it would be worse than none.

Delisted packages

Pulled by the registry during analysis: removed from the feed, not kept as a record of something nobody can install.

Security placeholders

npm swaps a held version for a 0.0.1-security stub. Nothing remains to observe, so it stays under review, marked as a placeholder.

Clean is published too

Every analysed version gets a verdict. A feed of hits alone offers no baseline for the other 98 percent.
